# HR Management Dashboard

A modern HR management web application built with React and Tailwind CSS. The application provides a comprehensive interface for managing employees, departments, and HR-related activities.

## Features

- **Dashboard:** Overview of key HR metrics and statistics
- **Employees:** Manage employee information and records
- **Departments:** Organize and track departmental structure
- **Reports:** Generate HR analytics and reports (coming soon)
- **Settings:** Configure application settings (coming soon)

## Technology Stack

- React.js
- TypeScript
- Tailwind CSS
- Modern UI with a white and blue color scheme

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```
git clone <repository-url>
cd hr-dashboard
```

2. Install dependencies
```
npm install
```

3. Start the development server
```
npm start
```

The application will be available at [http://localhost:3000](http://localhost:3000).

## Project Structure

```
src/
├── components/       # UI components
├── pages/            # Page components for each section
├── hooks/            # Custom React hooks
├── types/            # TypeScript type definitions
├── utils/            # Utility functions
├── context/          # React context providers
├── App.tsx           # Main component
└── index.tsx         # Application entry point
```

## Customization

The application uses Tailwind CSS for styling. The primary blue color scheme can be customized in the `tailwind.config.js` file.
